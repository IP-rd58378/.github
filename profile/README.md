<h2>二、从询价到验收</h2>
<p>询价给四项信息：城市、数量、用途、租期。用途要说明是否涉及视频上传，因为上行带宽是主要差别。信息给全，报价才准。</p>
<p>验收做三项：查 ASN 是否为法国本地运营商、查 rDNS 是否有运营商命名、连续三天记录出口是否漂移。三项都过再签批量。</p>
<h3>试用买几个</h3>
<p>买两个即可：一个测试登录，一个测试稳定性。登录测试看是否触发验证，稳定性测试看出口是否漂移。两项都过，说明这一批可用。</p>
